# Phase 진행 현황 조회

프로젝트의 전체 진행 현황을 파악하고 다음 행동을 안내합니다.

## 작업 순서

### 1단계: PROGRESS.md 조회

`.claude/phases/PROGRESS.md`를 읽어 다음을 파악한다:
- 전체 진행률 테이블 (Phase별 완료/전체 수)
- 현재 진행 중(🔄) 또는 검토 중(🔍) Phase
- 다음 예정 Phase (⏱️ 대기 중인 것 중 의존성이 충족된 것)

### 2단계: 현재 Phase 상세 확인

진행 중인 Phase가 있다면 해당 `.claude/phases/phase-X-*.md`를 읽어:
- 체크리스트 달성률 계산 (✅ 항목 수 / 전체 항목 수)
- 블로커 감지: 의존성 Phase가 완료되지 않았는데 진행 중인 경우
- 보류(⏸️) 항목이 있다면 이유 확인

### 3단계: 결과 출력

아래 형식으로 출력한다. 해당 항목이 없으면 그 줄은 생략한다.

```
📊 프로젝트 진행 현황
━━━━━━━━━━━━━━━━━━━━━━━

전체: XX/YY (ZZ%)
Phase 1: XX% │ Phase 2: XX% │ Phase 3: XX% │ Phase 4: XX%

━━━━━━━━━━━━━━━━━━━━━━━

🔄 현재: Phase X.Y - [작업명]
   체크리스트: N/M 완료 (ZZ%)
   의존성: [의존 Phase] ✅

⏭️ 다음: Phase X.Y - [작업명]
   조건: [의존성 또는 선행 조건]

⚠️ 블로커: [있다면 표시, 없으면 생략]
   [블로커 내용 설명]

📋 최근 완료
   ✅ Phase X.Y - [작업명] (완료일)
   ✅ Phase X.Y - [작업명] (완료일)
```

### 블로커 감지 기준

다음 중 하나라도 해당하면 ⚠️ 블로커로 표시한다:
- 현재 Phase의 의존성 Phase가 ✅ 완료 상태가 아닌 경우
- 검토 중(🔍) 상태가 장기간 지속되고 있는 경우 (리뷰 문서 생성일 기준)
- 보류(⏸️) 항목이 전체 체크리스트의 30% 이상인 경우
