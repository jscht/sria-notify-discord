# Phase 리뷰 시작

현재 진행 중인 Phase의 리뷰를 시작합니다.

## 작업 순서

1. **현재 Phase 확인**
   - `.claude/phases/PROGRESS.md`를 읽어 현재 진행 중인 Phase 확인

2. **Phase 문서 확인**
   - `.claude/phases/phase-X-*.md`에서 해당 Phase의 체크리스트 확인
   - 완료 기준 달성 여부 검증

3. **리뷰 문서 생성**
   - `.claude/docs/reviews/phase-X-Y-review.md` 파일 생성
   - 아래 템플릿 구조를 따름

4. **상태 업데이트**
   - Phase 문서의 상태를 🔍 검토 중으로 변경

## 리뷰 문서 템플릿

```markdown
# Phase X.Y: [작업명] 🔍

**상태**: 🔍 검토 중 (YYYY-MM-DD)
**우선순위**: [⭐⭐⭐ / ⭐⭐ / ⭐]
**의존성**: [이전 Phase 또는 "없음"]

---

## 📊 개선 작업 현황
### [작업 영역] [상태]
- [주요 구현 사항]

---

## 📝 작업 체크리스트
### 1. [작업 항목]
- [🔄] 세부 사항

---

## ✅ 완료 기준
- [🔄] 기준 1

---

## 📂 수정/생성된 파일 목록
| 파일 | 작업 | 변경 내용 |

---

## 🔍 검토 사항
### 코드 리뷰
- [ ] 항목

### 기능 테스트
- [ ] 항목

---

---

2. [ ] Git 커밋 및 PR 생성
3. [ ] PROGRESS.md 업데이트
```
