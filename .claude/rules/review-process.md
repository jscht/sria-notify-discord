# 검토 프로세스

PDCA 검토 단계(런타임 검증 → report → 피드백 → archive → 커밋·PR)의 상세 절차는 `.claude/docs/review-process.md`를 읽는다.
아래 규칙은 단계와 관계없이 항상 지킨다.

## 핵심 규칙

- **피드백 수신 시 즉시 반영하지 않음** — 수정 계획 제시 → 사용자 승인 → 진행. 승인 전까지 코드 수정 금지
- **사용자가 명시적으로 말하기 전까지 review 문서에 반영 금지**
- **Git 커밋·PR은 사용자 지시 시에만** 수행한다
- 런타임 검증은 Claude가 실행한 항목도 **사용자 확인 전에 통과 처리하지 않는다**
