# 에이전트 호출 정책 (Agent Invocation Policy)

사용자가 명시적으로 요청하거나, 아래 조건을 만족할 때만 호출한다.
호출 전에 **반드시 사용자에게 사용 여부를 먼저 묻는다**.

## 공통 규칙

1. **확인 우선**: 트리거 조건이 감지되면 곧바로 `Agent` 도구를 호출하지 않는다.
   먼저 한 문장으로 "{agent-name} 에이전트를 사용하시겠습니까?"라고 묻는다.
2. **거부 시**: 메인 컨텍스트에서 직접 처리한다.
3. **단순 조회 제외**: 아래 정의에 따라 "작업 지시"일 때만 트리거가 작동한다.
   "단순 조회"는 확인 없이 메인 컨텍스트에서 처리한다.

### 작업 지시 vs 단순 조회 (공통 정의)

| 구분 | 판정 기준 | 예시 |
|------|-----------|------|
| **작업 지시** | 파일 생성·수정·삭제 의도 / 설계서·계획서·코드 산출 요구 / 명령형·요구형 표현("만들어줘", "추가해줘", "변경해줘", "구현해줘", "설계해줘") | "Embed 추가해줘", "이 버튼 핸들러 구현", "슬래시 커맨드 설계서 작성" |
| **단순 조회** | 기존 상태·동작·이유 이해 목적 / 의문형·서술형 표현 ("뭐 하는 거야?", "어디 있어?", "왜 안 돼?") / 산출물 요구 없음 | "이 핸들러 뭐 해?", "현재 커맨드 목록", "왜 인터랙션 안 떠?" |

판정이 애매하면 **사용자에게 의도를 먼저 묻는다** ("조회만 하시는 건가요, 변경 작업인가요?").

## Discord Agent

### 확인을 띄우는 조건

**판정식: (Discord 맥락) ∧ (작업 지시)** — 둘 다 충족해야 트리거.

"작업 지시"는 공통 규칙 §3 정의를 따른다.
"Discord 맥락"은 아래 셋 중 **하나 이상**이 충족되면 인정한다.

#### (1) 명시적 단어
- 한/영: `discord`, `디스코드`, `봇`, `Discord Bot`

#### (2) Discord.js 도메인 용어
이 프로젝트에서 Discord 외 다른 UI가 없으므로, 아래 용어는 Discord 맥락으로 간주:
- 컴포넌트: `Embed`/`임베드`, `Button`/`버튼`, `Modal`/`모달`, `SelectMenu`, `ActionRow`
- 인터페이스: `슬래시 커맨드`/`slash command`, `인터랙션`/`interaction`, `Custom ID`, `ephemeral`
- 동작: `DM 발송`, `봇 이벤트`, `페이지네이션`
- 빌더: `EmbedBuilder`, `ButtonBuilder`, `ModalBuilder`, `SlashCommandBuilder`

#### (3) 파일·디렉토리 경로
- `providers/discord/**`, `events/listeners/**`, `events/handlers/**`
- `features/alarmSubscribe/**`, `features/recruitRequest/**`

### 판정 예시

| 메시지 | Discord 맥락 | 작업 지시 | 트리거 |
|--------|--------------|-----------|--------|
| "디스코드 알림 임베드 새로 만들어줘" | ✅ (`디스코드`, `임베드`) | ✅ (`만들어줘`) | **Yes** |
| "슬래시 커맨드 추가" | ✅ (`슬래시 커맨드`) | ✅ (`추가`) | **Yes** |
| "이 UI 흐름 설계해줘" (맥락 없음) | ❌ | ✅ | **No** — 의도 확인 필요 |
| "Firestore 스키마 설계" | ❌ | ✅ | **No** — 다른 에이전트 |
| "이 Embed 어디서 만들어져?" | ✅ | ❌ (조회) | **No** |

### 맥락 모호 시
"UI", "설계", "구현"만 있고 도메인/파일 맥락이 없으면 **사용자에게 먼저 묻는다**:
"Discord UI/인터랙션 작업이신가요?"

### 확인을 띄우지 않는 경우

- 단순 코드 읽기: "이 핸들러가 뭐 하는 거야?", "이 Embed 어디서 만들어져?"
- 상태 조회: "현재 등록된 슬래시 커맨드 목록", "지금 어떤 버튼들이 있어?"
- 디버깅 질문: "이 인터랙션 왜 안 떠?" (먼저 원인 파악 후 필요 시 제안)
- PDCA 사이클에서 이미 에이전트 흐름이 정해진 경우

### 확인 문구 예시

```
Discord Agent를 사용하시겠습니까?
(discord.js 14.17 UI/인터랙션 구현 전담, opus 모델, 비용 ↑)
```
