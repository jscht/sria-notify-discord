# 작업 라우팅 규칙 (Task Routing Rules)

"다음 뭐 해야 하지?", "뭐 하면 돼?" 같은 질문은 `/todo`, `/pdca status`, `/pdca next`
세 스킬 모두를 떠올리게 한다. 아래 기준으로 **하나로 확정**해 발동한다.

## 세 대상의 본질 축

| 대상 | 질문의 본질 | 범위 | 시간축 |
|------|------------|------|--------|
| `/todo` | 오늘 처리할 **ad-hoc 잡무** | 단발 항목 | 오늘 |
| `/pdca next` | **사이클/feature상 다음 행동** | Phase 단위 | 진행중 사이클 or 다음 feature |
| `/pdca status` | **전체 어디까지 왔나** | 프로젝트 전체 | 누적 현황 |

핵심 판별 질문: *"오늘치 자잘한 작업이냐(todo) / 정식 Phase의 다음 스텝이냐(next) / 전반 현황 파악이냐(status)"*

## 라우팅 결정 트리

```
"다음/뭐 해야" 류 질문
  │
  ├─ pdca 신호 없음 ──────────────→ /todo            (오늘치 ad-hoc 기본값)
  │
  └─ pdca 신호 있음
        ├─ 구체 액션 단어 있음 ────→ 해당 액션
        │     (현황/진행률/어디까지 → status,
        │      계획 → plan, 갭분석 → analyze ...)
        │
        └─ 구체 액션 단어 없음 ────→ /pdca next       (read-only·경량·실행 답 즉시)
```

### pdca 신호 정의

아래 중 하나라도 있으면 **pdca 맥락**으로 본다:

- 명시어: `pdca`, `phase`, `feature`, `매치율`, `사이클`
- 액션어: `plan`, `design`, `do`, `analyze`, `iterate`, `report`, `archive`, `cleanup`
- 상태 조건: 진행중 사이클 존재 (`.claude/docs/pdca-memory.json`의 `phase !== null`)

### 모호 시 `next` 우선 근거

pdca 맥락이지만 액션 단어가 모호할 때 `status`가 아닌 `next`를 먼저 돌린다:

- **read-only**: `next`는 상태를 변경하지 않는다 (사이클 완료 시에만 조건부 동기화).
- **경량**: 사이클 중이면 `pdca-memory.json`(~50토큰)만 읽는다. `status`는 전체 `pdca-status.json` 대시보드를 로드.
- **실행 가능한 답 즉시**: "뭐 해야 하지"의 답은 다음 실행 스텝이면 충분하다.
- **status는 상위집합**: 전체 진행률·블로커·완료이력이 필요하면 사용자가 **"현황"을 명시**했을 때만 `status`로 간다. (`status` 출력에 다음 추천도 포함되므로 정보 손실 없음)

## 판정 예시

| 메시지 | pdca 신호 | 액션 단어 | → 라우팅 |
|--------|-----------|-----------|----------|
| "pdca 뭐해야 해" | ✅ (`pdca`) | ❌ (모호) | **/pdca next** |
| "다음 뭐 하지" (사이클 진행중) | ✅ (진행중 사이클) | ❌ (모호) | **/pdca next** |
| "다음 단계 뭐야" | ✅ | ✅ (`다음 단계`) | **/pdca next** |
| "어디까지 했어" / "전체 현황" | ✅ | ✅ (`현황`) | **/pdca status** |
| "진행률 보여줘" | ✅ | ✅ (`진행률`) | **/pdca status** |
| "오늘 뭐 해야 하지" | ❌ | — | **/todo** |
| "남은 일 보여줘" | ❌ | — | **/todo** |
| "todo 다음" | ❌ | — | **/todo** |

## 경계 모호 시

`todo` / `pdca` 어느 쪽인지 끝내 판단이 안 서면(예: pdca 신호가 약하게 섞임)
**사용자에게 의도를 먼저 묻는다** ("오늘치 작업(todo)인가요, PDCA 사이클 작업인가요?").
추측으로 발동하지 않는다 (CLAUDE.md 추측 금지 원칙).
