# 기술 스택 (Tech Stack)

## Backend
- **Runtime**: Node.js 18 + TypeScript 5.1
- **Platform**: Firebase Functions (asia-northeast3, Serverless)
- **Framework**: Express 4.21

## Discord & Scraping
- **Discord**: discord.js 14.17
- **Web Scraping**: Playwright 1.47

## Database & Cache
- **Primary DB**: Firebase Firestore
- **Cache**: Redis 4.7

## AI
- **NLP**: Hugging Face Inference API (무료 모델)

## DevOps
- **Testing**: Vitest
- **Linting**: ESLint
- **CI/CD**: Firebase Hosting & Functions
